\# ⚕️ MediSentix



Healthcare Review Sentiment Analysis using NLP, Clustering \& RNN.



\## Features



\- Corpus to Excel Conversion

\- Sentiment Prediction

\- KMeans Clustering

\- RNN/LSTM

\- Confusion Matrix

\- Interactive Dashboard



\## Technologies



\- Python

\- Streamlit

\- Scikit-learn

\- TensorFlow

\- Pandas



\## Run Project



```bash

pip install -r requirements.txt

streamlit run app.py
